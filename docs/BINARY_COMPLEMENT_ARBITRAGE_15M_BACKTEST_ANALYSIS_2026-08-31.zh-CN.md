# Binary Complement Arbitrage 15m 回测分析（2026-08-31）

## 结论

15 分钟 BTC 市场的理论同快照套利密度略高于 5 分钟 BTC，但在加入现实预检和第二腿延迟后，仍没有形成可重复的双腿套利能力。

本轮只发现 1 个在 250 ms 预检后仍可双腿成交的历史机会；它在 0–100 ms 第二腿延迟场景中重复出现，手续费后收益约 0.07–0.17 USDC。样本数远低于 100 个质量门槛，且基准 250/250 ms 场景没有双腿成交、反而产生 0.653505 USDC 紧急退出亏损。因此 15m 不应直接进入实盘；可以进行独立 PAPER dry-run，以确认这类极低频机会在真实 REST 链路中是否存在。

## 延迟敏感性

| 确认/预检/第二腿 | 双腿 | 单腿 | 净收益 |

| 100/0/0 ms | 88 | 0 | +16.292155 USDC |

| 100/50/250 ms | 0 | 0 | 0 |
| 100/100/250 ms | 0 | 0 | 0 |
| 100/250/0 ms | 1 | 0 | +0.073617 USDC |
| 100/250/25–100 ms | 1 | 0 | +0.171728 USDC |
| 100/250/250 ms | 0 | 1 | -0.653505 USDC |
| 100/250/500 ms | 0 | 1 | -0.316094 USDC |

| 500/0/250 ms | 1 | 3 | -0.133905 USDC |
| 1000/0/250 ms | 1 | 1 | -0.157358 USDC |

零预检场景的正收益不能视为可实现收益；例如 100/0/250 ms 场景第二腿失败 29 次，占全部第一腿执行事件的 32.95%，必须依靠历史盘口模拟的紧急退出。

在预检延迟大于 0 的 23 个场景中，4 个场景显示正收益，但它们来自同一个独立机会在不同第二腿参数下的重复计算，并不是 4 次机会。只要第二腿延迟达到 250 ms，该机会就不再双腿成交。

## 与 5m BTC 对比

以下使用相同手续费和执行假设：

| 指标 | BTC 5m | BTC 15m | 判断 |
|---|---:|---:|---|
| 市场数 | 9,436 | 2,772 | 15m 样本较少 |
| 基准候选/市场 | 13.10 | 16.74 | 15m 高约 27.8% |
| 基标准入/市场 | 0.368 | 0.472 | 15m 高约 28.4% |
| 基准双腿成交 | 0 | 0 | 均不可执行 |
| 零延迟双腿成交/市场 | 2.31% | 3.17% | 15m 理论机会略多 |
| 零延迟净收益/市场 | 0.00424 | 0.00588 USDC | 15m 理论收益略高 |

15m 的改善只体现在同快照或零预检模型中。基准现实延迟下两个周期均为 0 次双腿成交，因此不能据此断言 15m 已解决 5m 的执行问题。

## 可行性判断

- 理论价差：存在，且 15m 略多于 5m。
- 现实延迟后的可执行价差：只观察到 1 个独立样本，证据不足。
- 当前自动结论：`NOT_READY_INSUFFICIENT_SAMPLE`。
- 降低深度、手续费或净收益门槛：不建议；主要瓶颈是执行深度与机会寿命。
- 直接实盘：不适合。
- 独立 15m PAPER dry-run：可以，作为低频机会和 REST 延迟验证，不应与 5m 结果混合。

## 下一步

1. 等 15m 下载同步完成后，可再运行一次最终全量回测；预计新增约 4% 市场，不太可能改变当前数量级结论。
2. 在服务器设置 `MARKET_PERIOD_MINUTES=15`，使用独立日志和结果目录运行 PAPER，不要与 5m 同进程混合。
3. 至少收集 100 个手续费后为正的独立信号，并要求真实 REST 最快组存在可重复的双腿可成交样本。
4. 若 15m dry-run 的 REST 双腿可成交仍接近 0，应同时终止 5m/15m 双 taker 路线，转向 maker 或其他执行结构。
