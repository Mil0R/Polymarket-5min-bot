## 四个预设特征

风险组每笔净 PnL 减补集为负，才符合原“风险组更差”的预期；各组重叠，不能相加。

| 预设组 | 组内 N / PnL | 补集 N / PnL | 每笔 PnL 差 | 描述性门槛 |

| 买 DOWN | 74 / +4.50 | 56 / +36.77 | -0.60 | True |
| signal ask [0.10,0.30) | 64 / +99.96 | 66 / -58.69 | +2.45 | True |
| 逆最近 30 秒 TWAP | 63 / +50.52 | 67 / -9.25 | +0.94 | True |
| 开盘距离 <1 bps | 67 / +33.97 | 63 / +7.31 | +0.39 | True |

当前 DOWN 组每笔较差约 0.60，逆 30 秒组较好 0.94、低报价组较好 2.45、近开盘组较好 0.39。仅 DOWN 在本次为负，近开盘此前的风险方向仍未延续；组间重叠与少数盈利的影响依然存在。四个特征未形成一致稳定的亏损划分，不应据此直接加过滤条件。

辅助门槛为每组与补集各至少 30 笔且有 5 个完整有效日。达到描述性门槛不等于方向稳定或因果证实；没有做辅助组独立显著性验收，不自动形成线上过滤。
